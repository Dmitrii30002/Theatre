# Репозиторий для проекта

Ветка main - основная.

## Запуск приложения

Для начала необходимо клонировать репозиторий (не забудьте перейти в рабочую директорию перед клонированием): <br>
```bash
git clone https://github.com/Dmitrii30002/Theatre.git
```

#### Backend
Для запуска бэка необходимо выполнить следующую команду, находясь в главной директории: <br>
```bash
docker compose -f deploy/docker-compose.yml up
```

## Структура проекта

scheme - каталог со схемами(архитектура, БД, апи и т.п.) <br>
api - документация api <br>
frontend - каталог для фронтенд части проект <br>
-- mockRequestData - каталог с моковыми результатами запросов <br>
backend - каталог для бэкенд части проекта <br>
deploy - каталог с файлом docker-compose для запуска приложения <br>
<br>
